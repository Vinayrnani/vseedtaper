Tape advances 2·π·20 = 125.66 mm / crank rev (crank drives roller; drum 0.5× via 40:20 mesh). Crank on roller axle (x=40, outside back wall); drum CCW picks up right, drops bottom-center. R→L layout: hopper wedge (right, mouth ~183) → drum (100) → shroud tunnel (58-84) → roller/crank (40) → spool (-6, west). Single wrap-around hopper: right wedge pickup (level top), 11→6 cover, hover pipe (ID6/OD10 L10, 10 gap) drops seeds at x=100 port. Two-stage forming: first-stage U (forming 37..70 + transit 70..126, seed drops at 100 into the open pocket) → 6-turner second stage (126..159: U-in, twin curl horns + inner tongue fold the 2 edges inside into an overlapping roll, near-closed exit reads as 6 end-on). Thread twister (2 arms, 6 orbits/drum rev via DRUM/C/TW meshed spurs) binds each rolled seed past the 6-turner → cushioned vertical pull nip (rubber sleeve, 1:1 via DRUM/P1/P2/PP short chain, spacing driver) → wind-up reel (core d10 step-up via shared PP-axle/TU pinion, slip clutch: fast empty, slips full). Minimal drum-driven gears only (module 2, dist=r1+r2), no belts, no long spine. Mounts — bottom: 6-turner + wind-up reel · side: twister + pull + drum (axles through walls) · top: hopper + shroud + input spools.
